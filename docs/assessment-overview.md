# Week 1 Assessment Overview — Supply Chain Network Planning in SAP SCM

## Assessment focus
This repository contains the Week 1 internship assessment on supply-chain network planning in SAP SCM. The work focuses on modeling the network, reviewing locations and transportation lanes, balancing demand and supply, and evaluating planning alternatives.

## Repository standard
The six-assessment series uses a consistent structure: a root README, the final assessment and supporting analysis under docs/, and editable process diagrams under diagrams/. Where a structured dataset is useful, it is stored separately under data/.

## Scope note
This is an internship learning assessment. Scenario assumptions, calculations, configuration guidance, and any simulated outcomes should be interpreted as illustrative unless explicitly supported by system evidence.
